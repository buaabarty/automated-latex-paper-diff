# v0.1.4

This patch fixes two reviewer-facing marking problems.

## Changes

- Float-level begin/end markers are now no-ops. Additions and deletions are
  still marked by `DIFadd`, `DIFdel`, `DIFaddFL`, and `DIFdelFL`, but a complex
  table or figure can no longer leave later unchanged text colored blue or red.
- BibTeX bibliographies are generated for both source trees and inlined into the
  temporary LaTeX sources before `latexdiff` runs. Added, deleted, and edited
  reference entries are therefore included in the marked manuscript.

## Verification

- Regression fixture with an added table followed by an unchanged Section 11.
- Regression fixture with added, deleted, and edited bibliography entries.
- `bash -n scripts/generate_marked_diff.sh`.
