# v0.1.1 - GHCR Docker Publishing

This patch release adds automated Docker image publishing.

## New

- Added a GitHub Actions workflow that builds the Docker image on pushes,
  pull requests, and release tags.
- Published images are available from GitHub Container Registry:
  `ghcr.io/buaabarty/automated-latex-paper-diff`.
- The README now documents prebuilt image usage, tag policy, and local build
  alternatives.

## Recommended Docker Command

```bash
docker run --rm \
  -v "$PWD":/work \
  ghcr.io/buaabarty/automated-latex-paper-diff:v0.1.1 \
  --old /work/paper-original \
  --new /work/paper-revised \
  --out /work/marked_diff_output \
  --tag major_revision
```

Use `latest` if you want the newest build from `main`.
