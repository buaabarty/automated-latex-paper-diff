# v0.1.3 - Global Underline/Strike Diff Markers

This patch release makes the review markup consistent across normal text,
figures, and tables.

## Fixed

- Additions now use visible underline markers throughout the generated TeX.
- Deletions now use visible strikethrough markers throughout the generated TeX.
- Table and float-safe `DIFaddFL`/`DIFdelFL` commands now use the same
  underline/strike definitions, so table cell edits are not color-only.
- The marker override is applied after `latexdiff` generation, so callers cannot
  accidentally switch the output back to color/font-only markup with
  `LATEXDIFF_FLAGS`.

## Why

Reviewers need to see every changed region clearly, including dense table cells
and caption text. Color-only markup is too easy to miss and does not survive
grayscale review workflows.
