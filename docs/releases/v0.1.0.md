# v0.1.0 - Initial Release

This is the first public release of Automated LaTeX Paper Diff.

## What It Does

- Generates a reviewer-facing marked PDF from old and revised LaTeX source trees.
- Keeps complex table and figure diffs compilable with safe `latexdiff` defaults.
- Adds scripted marking for whole newly added tables, which plain `latexdiff`
  can leave visually unmarked.
- Repairs common citation wrappers that can break `natbib` after `latexdiff`.
- Emits `table_diff_report.txt` so table/float marking coverage is auditable.
- Provides a Dockerfile for users who do not want to install TeX Live locally.

## Recommended Command

```bash
scripts/generate_marked_diff.sh \
  --old paper-original \
  --new paper-revised \
  --main main.tex \
  --out marked_diff_output \
  --tag major_revision
```

## Docker Command

```bash
docker build -t automated-latex-paper-diff:latest .

docker run --rm \
  -v "$PWD":/work \
  automated-latex-paper-diff:latest \
  --old /work/paper-original \
  --new /work/paper-revised \
  --out /work/marked_diff_output \
  --tag major_revision
```

## Status

The project is intended for practical manuscript-revision workflows. It is not a
semantic diff engine; heavily macro-driven papers may still need project-local
post-processing through `--replace-latex`.
